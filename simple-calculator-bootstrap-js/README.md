# Simple Calculator

A responsive calculator made with:

- HTML
- Bootstrap 5
- CSS animations
- Vanilla JavaScript

## Features

- Addition, subtraction, multiplication and division
- Percentage
- Clear and delete
- Keyboard support
- Responsive on mobile, tablet and desktop
- Smooth button and card animations

## Run

Open `index.html` in a browser.

## GitHub Pages

Upload the project to a GitHub repository and enable:

Settings → Pages → Deploy from branch → main → / (root)
